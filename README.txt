CAN'T CATCH ME — Stage 1

How to use:
1. Upload index.html, style.css, and game.js to the root of your GitHub repository.
2. In GitHub, open Settings > Pages.
3. Set deployment to the main branch and the root folder.
4. Open the GitHub Pages URL after deployment finishes.
5. Click PLAY and use WASD + mouse.

The game uses Three.js from the cdnjs CDN, so an internet connection is required.
